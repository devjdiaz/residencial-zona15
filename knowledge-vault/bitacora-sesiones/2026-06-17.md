# Sesión 2026-06-17 — Visor y editor de contrato (TipTap)

## Qué se hizo

Feature completo: visualización inline del PDF del contrato y edición tipo Google Docs con TipTap.

### 1. Migraciones DB

**`supabase/migrations/2026-06-17_contract-template.sql`**
- Crea `contract_template (key TEXT PRIMARY KEY, value JSONB, updated_at TIMESTAMPTZ)`
- RLS habilitado con policy `template_admin_select` (solo admin/super_admin pueden leer)
- Seed: `landlord`, `banks`, `clauses` (14 cláusulas con `on conflict do nothing`)

**`supabase/migrations/2026-06-17_contract-template-body.sql`**
- Seed: `body_json` — contrato completo en formato Prosemirror JSON (TipTap)
- Usa `on conflict do update` para permitir re-ejecución
- Todos los placeholders `{NOMBRE_INQUILINO}`, `{RENTA}`, etc. están en el JSON como texto plano

> [!warning] GRANT requerido
> En proyectos Supabase nuevos hay que ejecutar manualmente:
> ```sql
> grant select, insert, update, delete on contract_template to service_role;
> grant select on contract_template to authenticated;
> ```
> Sin esto el API devuelve `500: permission denied for table contract_template`.

### 2. Dependencias nuevas

```
@tiptap/react  @tiptap/pm  @tiptap/starter-kit
```

### 3. `ContractPDF.tsx` — reescrito

- Acepta `bodyJson: PmNode | null` (Prosemirror JSON) en lugar de template estructurado
- Función `replacePlaceholders(node, vars)` — recorre el árbol JSON y sustituye `{PLACEHOLDER}` en nodos de tipo `text`
- Función `renderPmNode(node, key)` — convierte nodos Prosemirror a elementos `@react-pdf/renderer`
  - Soporta: `doc`, `heading` (H1/H2/H3), `paragraph`, `bulletList`, `orderedList`, `listItem`, `hardBreak`, `text` (con marks `bold` e `italic`)
- Exporta: `replacePlaceholders`, tipos `PmNode`, `Vars`
- Secciones siempre auto-añadidas por el componente (no editables): persona adicional, parqueo, firmas

### 4. API route `/api/contracts/[contractId]/pdf/route.ts` — actualizado

- Fetcha `body_json`, `landlord`, `banks` de `contract_template`
- Construye mapa `vars: Vars` con 21 placeholders
- Llama `replacePlaceholders(bodyJson, vars)` antes de pasar al componente PDF
- Cláusula 7 (`{CLAUSULA_DEPOSITO}`) se resuelve dinámicamente según si hay depósito pagado en `income_extras`

### 5. API route `/api/admin/contract-template/route.ts` — nuevo

- `GET`: devuelve `{ landlord, banks, clauses, body_json }` — requiere admin/super_admin
- `PUT`: recibe `{ key, value }`, hace upsert, escribe en `audit_log`

### 6. `ContractPDFViewer.tsx` — nuevo componente

- Modal grande (95vw × 90vh, z-[60])
- **Modo vista**: iframe apuntando a `/api/contracts/{id}/pdf?t={timestamp}` (cache-bust)
- **Modo edición**: editor TipTap con StarterKit
  - Toolbar: B, I, H1, H2, H3, lista con viñetas, lista numerada, undo, redo
  - Panel inferior con chips de placeholders (clic → copia al portapapeles)
  - Al entrar: fetch `body_json` → `editor.commands.setContent(data.body_json)`
  - Al guardar: `editor.getJSON()` → PUT `body_json` → recarga iframe

### 7. `ContractInfoDialog.tsx` — modificado

- Reemplaza el `<a target="_blank">` por un botón que abre `ContractPDFViewer` inline
- Envuelto en Fragment `<>` para soportar el modal como sibling

### 8. `globals.css` — añadido

- Clase `.tiptap-contract` con estilos serif para el editor (Georgia 14px, headings, párrafos, listas)

### 9. `app/admin/plantilla/page.tsx`

- Redirige a `/admin/rooms` (la página de plantilla estructurada fue descartada)
